# LumaSync 0.2.2

## What's new

- Use the left and right arrow keys to adjust selected screen-sync settings, LED counts, effect speed, RGB channels, and hue-correction values.
- Refines the main window and color picker layout, including consistent header buttons, centered labels, and a close control in the picker's top-right corner.
- Aligns the LumaSync wordmark stripe with the text and removes the decorative heart.
